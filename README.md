# my_notebooks
Записная книжка с не очень важным кодом но написанным самим и для себя 

## calc_distance.hs 
скетч для запуска в Termux в терминале для быстрого рассчёта расстояния до объекта при известной высоте обьекта

### Пример (в терминале Linux)
> ./calc_distance.hs 1.60 0.003
> 341.33334

то есть , расстояние до объекта высотой 1.6 м,который визуально на вытянутой руке имеет высоту 3 мм (0.003 м) , составляет примерно 341 м.
